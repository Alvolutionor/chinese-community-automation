# SegmentFault

## Discover

Prioritize well-specified technical questions that remain unresolved. Inspect
tags, environment, error messages, attempted solutions, and existing answers.
A question about how code works is not necessarily a tool-shopping request.

## Draft

Give a diagnosis, concrete next check, or supported solution to the exact question.
Include complete code only when it helps the answer. State the user's actual role
if discussing their own tool; a product recommendation cannot replace the missing
technical explanation. Do not present untested code as a verified fix.

## Platform-specific checks

The community management rules address repetitive advertising, deceptive links,
fabricated experience, coordinated engagement, repeated answers, and harassment.
The official article guide also distinguishes technical contributions from
advertising. Inspect current rules before promotion; an optional personal
introduction in an article is not permission for promotional Q&A answers.
