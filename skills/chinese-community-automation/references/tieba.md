# Baidu Tieba

## Discover

Choose bars that fit the actual use case. Read current pinned bar rules and any
designated help, recommendation, trading, or advertising threads before searching
individual posts. Search "任务 + 求助/求推荐/替代" inside the relevant bar where
the available interface supports it. Record the post and specific floor/comment.

## Draft

Respond to the concrete request in the appropriate thread. Match the discussion's
plain language without forced memes or pretending to be an established member.
Do not bump old threads for exposure, copy identical replies across bars, or frame
a seller recommendation as an independent user's experience.

## Platform-specific checks

Bar rules are local and can prohibit product, store, group, or service promotion
even if the topic is relevant. Dedicated advertising or trading threads only grant
the permission actually described there. Check current rules and avoid treating
old moderator handbooks as current user marketing policy.
