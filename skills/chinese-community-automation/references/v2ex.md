# V2EX

## Discover

Choose nodes based on the actual product and request. Search topic titles and
replies for concrete recommendation, alternative, or implementation needs.
Read the opening post, additions, reply dates, and relevant replies before drafting.
Use the original topic URL plus a visible reply locator, without fabricating an
anchor the page does not expose.

## Draft

Use direct, concise technical prose. Answer the actual constraint: operating
system, deployment, privacy, cost, performance evidence, or maintenance. State
your connection to a recommended project and any relevant limits. Avoid an
advertising landing-page voice, generic praise, and repeated link drops.

## Platform-specific checks

For an explicitly requested original post, the official node guide distinguishes
independent creations in `create` from company marketing in `promotions`.
Inspect the current node description and classify the actual intent. A product
being independently developed does not make every sales post a creation-sharing
post. These node rules for topics do not create blanket permission for promotion
in replies under another person's topic.
