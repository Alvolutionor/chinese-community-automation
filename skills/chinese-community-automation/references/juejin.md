# Juejin

## Discover

Look for technical workflow questions in relevant articles, comments, and short
discussions. Search a concrete task or error together with "求助", "有没有工具",
"替代", or a technical constraint. Read the surrounding article before treating a
comment as an independent request. Distinguish project sharing from paid campaigns.

## Draft

For a comment, give the missing technical point or next useful check. For an
explicitly requested article, use real implementation evidence and explain the
tradeoff; do not wrap a product pitch in a fabricated engineering case study.
Only include code the task needs, with complete runnable context where necessary.
Follow the user's code-comment rules and do not invent measurements.

## Platform-specific checks

Inspect the current content rules linked from the platform and any event-specific
requirements. Campaign rules may prohibit AI-written entries or impose originality
conditions; do not treat one campaign's requirements as site-wide policy.
Read-only access does not authorize scraping, endpoint reversal, or a marketing
reply in every technical discussion.
